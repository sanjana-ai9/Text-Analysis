# Text Analysis Using Python

## About the Project

This is my Task 6 project for the Veda Technology internship. In this project, I used Python to analyze a sample paragraph and find useful information about the text.

## Objectives

* Count the total number of words.
* Count the total number of characters.
* Count the vowels in the text.
* Identify repeated words.

## Tools Used

* Python
* Jupyter Notebook

## Concepts Used

* Variables
* Strings
* Loops
* If conditions
* `split()` and `len()` functions
* Dictionary and Counter

## How It Works

First, I created a sample paragraph and stored it in a variable. Then, I used Python to count the words, characters, and vowels. Finally, I identified the words that appeared more than once.

## What I Learned

Through this task, I learned how to process text using Python. I also practiced loops, conditions, and counting repeated words.

## Conclusion

This project helped me understand the basics of text analysis and how Python can be used to process textual data.
